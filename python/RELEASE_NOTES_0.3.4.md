# conformal-oracle 0.3.4: R7-aligned release candidate

Prepared locally, documentation updated 2026-09-06. No publication is implied
by this file; check PyPI for released versions.

## Included changes

- The previously prepared bootstrap correction is retained: replicates use
  `conformal_quantile`, the same estimator as the reported shift. This changes
  bootstrap intervals relative to the published 0.3.2 package, not the point
  estimates. No stored manuscript result is regenerated by this release work.
- README, methodology, conventions and API descriptions are aligned with
  *Conformal Recalibration of Extreme Tail Quantiles under Temporal Dependence*
  (R7). The scalar displacement is not a new miscalibration component or a
  new score decomposition; priority is attributed to Gneiting and Resin.
- The finite-rank/maximum-score fallback and the scope of the dependence
  theorem are explicit. Lower Quantile Score is better; corrected coverage
  does not validate the base forecast.
- Detailed documentation and known limitations are included in the source
  distribution. Version metadata remains 0.3.4, the existing unpublished
  candidate, with no new algorithm or signature changes from that candidate.

## Not included

- No separated-estimator API, automatic mixing-rate estimation or execution
  of the R7 proxy-gap experiment.
- No implementation of the paper's pre-deployment indication rule.
  `classify_regime` remains a descriptive correction-magnitude diagnostic.
- No repair of legacy `R_bootstrap_ci` field semantics: see `KNOWN_ISSUES.md`.
- No new model inference, manuscript simulations, datasets or table outputs.

The existing static/rolling computations and compatibility imports are
preserved. Optional forecaster libraries remain optional. Historical example
notebooks use older evaluation protocols and are not current R7 replication
instructions.
