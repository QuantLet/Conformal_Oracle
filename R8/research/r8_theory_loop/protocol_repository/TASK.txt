## Per-pair estimators (calibration block only, never test data)

For each pair, with calibration scores S₁..Sₙ, p = 1 − α, conformal shift Cₙ = S₍ₖ₎, k = ⌈(n+1)p⌉:

- **Ω̂** — long-run variance of the hit indicators 1{Sₜ ≤ Cₙ}: Bartlett/Newey–West with bandwidth ⌊4(n/100)^{2/9}⌋; also report Andrews automatic bandwidth as sensitivity. Floor at α(1−α)/10 and flag any pair hitting the floor.
- **f̂\*** — marginal score density at Cₙ. Primary: Gaussian kernel, Sheather–Jones bandwidth on the full calibration sample. Secondary: Siddiqui–Bloch–Gastwirth spacing estimator with m = ⌊n^{4/5}⌋ spacings. Report both; the primary is the one used downstream, and the plan says so before the run.
- **ĥ²** — local miscalibration in the h/√n parameterisation. The naive plug-in n·Cₙ² is biased upward by approximately Var(Cₙ) ≈ Ω/(n f\*²). Use the bias-corrected ĥ² = max(0, n·Cₙ² − Ω̂/f̂\*²). Report the fraction of pairs floored at zero.
- **B̂** — removable error ∫₀^{Cₙ}(F̂_S(u) − p) du from the calibration ECDF. Note in the plan that this is in-sample and optimistic; it enters only the descriptive comparison, not λ̂.
- **Predicted estimation cost** Âₙ = Ω̂/(2n f̂\*). Report in QS units × 10⁴, same scale as the manuscript.
- For Prop 4.4: with σ̂ₜ the 20-day trailing return SD already used for Vol-ERM, standardise Zₜ = Sₜ/σ̂ₜ, estimate g = density of Z at its calibration (1−α)-quantile (same kernel rule), and A = mean σ̂ₜ, B = mean σ̂ₜ² / mean σ̂ₜ, C = 1/mean(1/σ̂ₜ). Compute the boundary statistic Δ̂ = g²ĥ_Z² − v(B−C)/(A−C), v = α(1−α), with ĥ_Z² bias-corrected the same way as ĥ².

### Synthetic validation (must pass before the panel)

Use the GARCH(1,1) Monte Carlo already in the pipeline (ω = 1e-5, α₁ = 0.10, β₁ = 0.85; Normal and Student-t(5) innovations; 500 histories; n ∈ {250, 500, 1000, 2000}). Truth for Ω and f\* is available by simulation of the score process at long horizon. Criteria fixed in the plan: median relative error of Ω̂ and f̂\* under 15% at n = 1000; coverage of the implied Var(Cₙ) within [85%, 98%] of the empirical variance across histories. If a criterion fails, report the failure and the sample size at which it starts holding; do not proceed to the panel with an estimator that fails at n ≈ 700.

Also verify the expansion itself: simulated E[static − raw] against −B + Ω/(2nf\*) at each n, with the same relative-discrepancy reporting used for Figure 3.
