Every one of the 126 degenerate pairs has n₁₁ = 0 exactly, so there is genuinely no consecutive-violation evidence in them — the test is not missing clustering there, there is nothing in that statistic to miss.

## Verdict

Aggregate clustering is real: 397 consecutive-violation pairs against 88.9 expected under random placement, a factor of **4.47**.

**But the tempting headline — "clustering is present and the standard test cannot see it" — is wrong, and the data say something more damaging.** Where the independence test is defined it rejects in **62%** of pairs. The excess is not invisible to the test; it was invisible in the *table*, because the 126 pairs with n₁₁ = 0 were counted as passes.

So the corrected reading is that conditional coverage is **worse** than the paper reports, not better-than-it-looks. That aligns with Referee 1's point (viii) rather than answering it, and it makes the convention fix more urgent, not less.

The constructive extension survives but changes shape: pooling across assets is worth doing for the 126 pairs where per-asset evidence is absent by construction, not because the per-asset test is weak where it applies.
